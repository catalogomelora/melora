# MELORA · Catálogo

Sitio estático (HTML, CSS y JS). No necesita instalar nada.

## Publicar en GitHub Pages
1. Crea un repositorio y sube todo el contenido de esta carpeta (`index.html`, `styles.css`, `app.js`, `productos.js`, `img/`).
2. En el repositorio: Settings → Pages → Branch `main` / carpeta `/ (root)` → Save.
3. En un par de minutos tendrás el enlace para compartir con tus clientes.

## Editar
- WhatsApp, categorías y valor del envío gratis: parte superior de `app.js`.
- Productos: `productos.js` (copia un bloque, cambia los datos y pon la foto en `img/`). Para una oferta agrega `"antes": 30000`.

## Enlaces por producto
Abre `enlaces.html` en tu sitio publicado (ej. tu-sitio/enlaces.html) y copia el enlace de cada producto para tus anuncios.
